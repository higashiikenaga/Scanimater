# Scanimater

1970年代のアナログ・コンピュータアニメーション装置 **Scanimate** の映像を、ブラウザ上で再現して **MP4 / WebM 動画として書き出せる** エミュレーターです。インストール不要、外部ライブラリなしで動きます。

## 使い方

1. `index.html` を Chrome または Edge で開く（ローカルで開く場合は `python3 -m http.server` などで配信するのが確実です）
2. 右パネルの **プリセット** を選ぶか、原稿（文字・画像・図形）を設定する
3. プレビュー下の **キーフレームの帯** で動きを作る
   - 「＋ キー追加」で再生位置にキー（A, B, C, …）を追加。いくつでも置けます
   - キーをクリックで選択、ドラッグで時刻を移動。「次のキーへ」で区間ごとのイージングを選べます
   - キーを選んだ状態でパラメータを動かすと、そのキーだけが変わります
   - 「全キー共通」では、キー同士の差を保ったまま全キーが動きます
   - プレビューをドラッグすると位置、Shift＋ドラッグで回転を直接指定できます
   - 「回転の中心 X/Y」でロール回転の軸をずらせます（端を軸にしたスイングなど）
   - ◆ が付いている項目が、キーごとに値が異なる（アニメーションする）項目です
   - ラベルをダブルクリックすると初期値に戻ります
4. **書き出し** で解像度・fps・形式を選んで「動画を書き出す」

書き出しは WebCodecs を使ってフレーム単位でオフラインレンダリングするので、PC が遅くてもコマ落ちしません（WebCodecs が使えないブラウザでは実時間録画に切り替わります）。

## 再現している Scanimate の仕組み

| 実機 | このエミュレーター |
| --- | --- |
| ライトボックス上のハイコントラスト原稿をカメラで撮る | 原稿テクスチャ。カメラのピントのボケはミップマップで表現 |
| 高解像度 CRT の走査線を、ランプ電圧と波形発生器で偏向させて画を曲げる | 走査線1本ずつを帯状ポリゴンにして、頂点シェーダーで偏向（位置・サイズ・3Dフリップ・リボンねじれ・横波/縦波・波紋・曲げ・テーパー・ジッター） |
| ビームの移動が速い所は暗く、遅い所・折り返す所は明るい | ビーム速度から輝度を補正。線が重なれば加算されて明るくなる |
| 走査線の数・太さを変えるとラスターが見える | 走査線数・ビーム幅・地明かり・線間隔の偏り |
| フィルムの多重露光で残像の帯を作る | 過去の時刻のパラメータで同じラスターを重ね描き（多重露光） |
| P4 蛍光体の残光 | ピークホールド付き指数減衰 |
| 再撮した白黒映像をカラライザーで階調ごとに着色 | 再撮カメラのボケを通した輝度を階調バンドに分けてパレットへ割り当て。色相の循環（カラーサイクル）・画面縦グラデ・ホワイトコア |
| 光学系のにじみ | グロー（dual filter）とハレーション |
| 2インチ VTR / NTSC 放送の質感 | 走査線・色にじみ（輝度は鋭く色差だけ広がる）・ノイズ・テープの揺れ・周辺減光 |

速度系のパラメータ（波の速度・ねじれ回転・カラーサイクルなど）は位相として時間積分しているので、キーごとに速度を変えても波が飛びません。旧バージョンの A/B 形式のプロジェクトも読み込めます。

## ファイル構成

- `index.html` … 画面とスタイル
- `src/engine.js` … WebGL2 のレンダリングパイプライン
- `src/params.js` … パラメータ定義・パレット・プリセット
- `src/source.js` … 原稿の生成（文字・画像・図形）
- `src/app.js` … UI・タイムライン・書き出し
- `src/muxers.js` … 依存なしの MP4（H.264）/ WebM（VP9）コンテナ書き出し

プロジェクトは「プロジェクト → 保存」で JSON に保存・読み込みできます。編集内容はブラウザにも自動保存されます。
